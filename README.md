# StayNest – PG & Hostel Management Website

A responsive front-end demo website for a PG / hostel. It includes:

- Welcome / hero section
- Available room types with sample prices and availability
- Room filters (all, shared, private)
- Facilities and amenities
- Sample daily food menu and meal timings
- Resident rules and guidelines
- Complaint and support information
- Contact details and enquiry form
- Mobile-friendly navigation

## Run the website

1. Extract `pg-hostel-management-website.zip`.
2. Open the `pg-hostel-management-website` folder.
3. Double-click `index.html` to open it in a browser.

No build tools are required.

## Customize before publishing

This is a demonstration template. Replace the sample property name, address, phone number, email, room prices, room availability, food menu, policies and support process with accurate information for your property.

The enquiry form uses a `mailto:` link. Change `hello@staynest.example` in `index.html` and `script.js` to the real property email address. For a production website, connect the form to a secure backend or form service.

Photos are loaded from Unsplash, and Google Fonts are loaded online, so an internet connection is needed for those assets. The example prices and vacancies are placeholders, not live listings.
